# קורקומיין - ראשון בבוקר: חבילת הפקה לשירות וידאו AI

החבילה מתאימה לכל שירות שעושה Image-to-Video: Higgsfield, Kling, Runway, Veo, Seedance, Hailuo ודומים.

## מה יש כאן

| קובץ | מה זה |
|---|---|
| `storyboard.jpg` | כל 33 השוטים במבט אחד, עם זמן ואורך |
| `shots.csv` / `shots.json` | לכל שוט: זמן, אורך, מילים, פרומפט באנגלית, מצלמה, פרומפט שלילי, פריים פתיחה ותמונות רפרנס |
| `start_frames/shotNN.jpg` | פריים פתיחה נקי, בלי כתוביות, ב־1080p |
| `refs/` | הדמויות מהקיט (גוף מלא, רקע שקוף), התופים, הכרזות, הכותרת והרקעים |
| `song.mp3` | ההקלטה המקורית |
| `lyrics.srt` | הכתוביות לפי הזמנים שסימנת |
| `assemble.py` | חותך את הקליפים לפי השיר ומרכיב את הקליפ הסופי |

## תהליך עבודה

1. **מבחן לפני הכול**, כמו שכתוב בתסריט. צור קודם את שוט 07 (הליכה ליד הקיר), שוט 15 (הלהקה) ושוט 12 או 14 (המטוס). אם הפנים והכלים נשמרים, ממשיכים.
2. **לכל שוט:**
   - מעלים את `start_frames/shotNN.jpg` כ־Start frame / First frame.
   - מעלים את התמונות מעמודת `references` כ־Reference / Character / Element (רוב השירותים מקבלים עד 4 עד 7).
   - מדביקים את `prompt` ואת `camera`, ואם יש שדה Negative prompt, מדביקים את `negative`.
   - בוחרים אורך לפי `generate_s` (5, 10 או 15 שניות), יחס 16:9, 1080p אם אפשר.
   - **מכבים יצירת אודיו.** המוזיקה היחידה היא ההקלטה המקורית.
3. **שומרים** את התוצאה בתיקייה `clips/` בשם `shot01.mp4` עד `shot33.mp4`.
4. **מרכיבים:**
   ```
   python3 assemble.py           # final.mp4
   python3 assemble.py --subs    # final_subs.mp4, עם כתוביות צרובות
   python3 assemble.py --offset 12=0.8   # שוט 12 יתחיל 0.8 שניות לתוך הקליפ
   ```
   שוט שעדיין לא נוצר יוצג מתוך `korkomain_kit_1080p.mp4`, כך שאפשר לצפות בעריכה בכל שלב.
   צריך ffmpeg ו־Python 3.

## טיפים

- **עקביות דמויות:** תמיד צרף את קובץ הדמות מ־`refs/`, גם כשיש פריים פתיחה. ב־Higgsfield אפשר לשמור כל דמות כ־Element או Character ולהשתמש בה בכל השוטים.
- **טקסט בעברית:** מודלי וידאו כותבים עברית גרוע. הפרומפטים אומרים לא לכתוב טקסט, ואת הכתוביות ואת "יהיה כאן טוב" מוסיפים בעריכה.
- **שוטים ארוכים** (17, 18, 19, 20, 21, 29, 33 ארוכים מ־10 שניות): צור 15 שניות, או שני קליפים של 10 שניות וחבר. `assemble.py` חותך לאורך המדויק, ואם הקליפ קצר הוא מקפיא את הפריים האחרון.
- **סנכרון לקצב:** כל החיתוכים כבר נמצאים על הפעמות (161.5 BPM). כדי שתנועה בתוך שוט תיפול על מכה, הזז אותה עם `--offset`.
- **עלות משוערת:** סך הכול כ־295 שניות יצירה, 33 קליפים, לפני ניסיונות חוזרים. חשב פי 2 עד פי 3 לבחירת הטייק הטוב.
